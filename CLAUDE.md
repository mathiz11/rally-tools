# Rally Tools — project conventions

## Language

- **All code comments, JSDoc, documentation (`README.md`, `docs/*.md`), test names, commit messages and any new written material must be in English.**
- When adding or editing code, write comments in English; if you touch a French comment, translate it.
- **Exception — the product UI stays in French** (labels, aria-labels, page titles, meta descriptions, number formatting, route slugs such as `/essence`). Do not translate user-facing strings; quote them verbatim (e.g. « Calculer ») when referenced in docs.
- Identifiers (variables, functions, types, files) are in English.
